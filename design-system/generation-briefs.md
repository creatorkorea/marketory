# 이미지 제작 사양 요약

제작 수단: 내장 Image Gen. 각 이미지를 독립 호출했고 기존 선택 시안을 실제 이미지 경로로 첨부했습니다. 다음 내용은 재작업을 위한 **프롬프트 축약본**이며 원문 전체 로그가 아닙니다. 저장 이미지는 생성 원본을 복사했으며 프로그램으로 자르거나 재색칠하지 않았습니다.

## 생성 이미지와 구현 계약의 차이

생성 이미지의 라벨·상태 색·컨트롤 형태는 일부 근사치다. 기본 보드에 빠진 접수 완료 상태, 취소 사유 입력 형태, SENT 표기, EXPIRED 설명, 필드 오류 위치, 타이포그래피는 COMPONENTS/UX-CONTRACT가 우선한다. 버튼의 미묘한 질감·그라데이션·장식 손글씨는 구현하지 않는다.
