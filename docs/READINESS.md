# 개발 및 운영 전 결정 목록

**Vercel(웹) + Render(API) + Supabase(DB·인증·파일)** 구성이며, 2026-10-12 사용자가 creatorkorea 계정과 Render 무료 범위를 지정했습니다. 무료 인스턴스가 없는 Render Background Worker 배포는 보류합니다. [배포 구성](DEPLOYMENT.md)에 결정 범위를 기록했습니다. Supabase·OTP·Storage·Resend의 로컬 연결은 검증했고, Vercel 웹·Render 무료 API 배포와 웹→API→DB health, 비로그인 차단은 검증했습니다. 2026-10-23 기준 합성 테스트 마켓에서 공개 로그인·신청·보완·선정·참가확정·배치·안내·취소를 검증했습니다. [MVP 통합 결과](qa/MVP-VERIFICATION.md)에서 공개 확인과 로컬 전용 범위를 구분합니다. 실제 행사 모집 개시는 준비 단계입니다. 그 외 아래 항목은 미확정 또는 미검증입니다. 문서의 시안 예시는 실운영값 승인 근거가 아닙니다.

## 상태와 증거 작성 방식

각 항목은 미확정 → 결정됨 → 검증됨으로 구분합니다. 결정한 문구만으로 실제 수신·복원·권한 차단이 검증된 것은 아닙니다. 담당 역할은 실제 인물 배정이 아닙니다. 담당자·결정일·설정 위치·마스킹된 증거 링크를 확인 후 추가합니다. 비밀키나 개인정보 원문을 이 문서에 붙이지 않습니다.

## 출시 판단

MUST 기능의 관련 AC와 전체 E2E 결과, 운영 항목의 완료 증거, 미해결 문제의 영향이 확인되어야 출시를 판단할 수 있습니다. 테스트 제외는 이유·영향·결정자를 남기며 필수 계약을 임의로 제외하지 않습니다. 현 단계에서 서비스 출시 가능 또는 자운대 실증 완료로 표기하지 않습니다.

## 운영 준비 우선순위 — 2026-10-23

[통합 검증 결과의 운영 준비표](qa/MVP-VERIFICATION.md#실제-운영-전-남은-준비)를 현재 실행 목록으로 사용한다. 실제 행사 정보·정책과 담당자 배정, 실기기 및 실제 역할 검증, 백업/복구 계획, 안내 전달 방식, 모니터링·성능 조건을 모집 전에 확정한다. 전체 백업은 사용자 결정으로 보류 상태이며 진단 파일 확인으로 완료 처리하지 않는다. 상시 worker도 계속 보류한다. 기존 단회 메일 수신 확인을 상시 발송 운영 승인으로 해석하지 않는다.
