# 개발 로드맵

이 문서는 최신 명세를 **의존 순서와 검증 묶음으로 정리한 로드맵**입니다. P0와 P1/P3 백엔드 기반을 구현했습니다. 실제 인증 연결과 후속 업무 화면은 남아 있습니다. 각 단계 착수 시 관련 명세를 읽고 작은 구현 작업으로 분해합니다.

## P0 개발 기반과 경계 고정

- [x] Next.js·FastAPI·Python·Node 버전과 패키지 관리자, 실제 실행 명령·잠금파일 결정.
- [x] 웹·API·타입·migration·테스트 폴더 구성과 로컬 전용 환경변수 샘플 준비.
- [x] 실제 DB 트랜잭션 접근 방식·worker 실행 방식·OpenAPI 타입 생성 경로 결정.
- [x] 토큰·Pretendard·앱 기본 프레임 연결. 레스터 UI 시안을 그대로 버튼으로 사용하지 않음.
- [x] 로컬 health 확인·타입 검사·최소 테스트가 실행되는 절차 기록.

기록: [로컬 개발 안내](LOCAL-DEVELOPMENT.md), [P0 검증](P0-VERIFICATION.md). Docker build·외부 서비스 연결은 미검증이며 worker 업무 handler는 후속 단계입니다.

완료 증거: 재현 가능한 로컬 시작 절차, 버전 고정, health 응답, 타입 검사 로그. 외부 production 프로젝트 생성은 별도 운영 작업입니다.

## P1 인증과 프로젝트 권한

현재: [백엔드 기반 구현](P1-P3-IMPLEMENTATION.md)과 [OTP·계정 UI](AUTH-SETUP.md). provider 검증 adapter·bootstrap·me·프로젝트 조회·권한 helper와 로컬 테스트, 이메일 OTP·세션·로그아웃 화면을 구현했습니다. 실제 Supabase/OTP 연결 및 아래 전체 기능 연결 기준은 아직 완료 처리하지 않습니다.

- [ ] users와 auth 연결·공개 셀러 bootstrap·운영자 부여 경계 구현.
- [ ] 본인 소유권·project_members·역할별 조회/변경/파일/출력 검사 기반 구성.
- [ ] 사용자·프로젝트 격리 테스트와 권한 회수 후 재검사.

검증 연결: E2E-11, E2E-13, E2E-14, E2E-22, E2E-25, E2E-33. 파일·출력 관련 항목은 후속 기능이 연결된 뒤 통합 실행하며 여기서 조기 통과 처리하지 않습니다.

## P2 프로젝트 설정과 행사 경계

- [ ] 프로젝트 생성·정책·기한·정원·공개/마감·재검토·종료 구현.
- [ ] 실제 운영값과 예시 데이터를 분리하고 필수 설정 전 모집 공개 차단.
- [ ] 모집기한·보완기한·확정기한·행사 종료를 구분.

검증 연결: E2E-01, E2E-21, E2E-24, E2E-28, E2E-34. 후속 신청·배치 기능의 시간 경계는 해당 단계에서 재검증합니다.

## P3 공통 변경 요청과 복구

현재: DB core와 로컬 검증 구현. IN_PROGRESS commit 차단·동시 요청·replay·FAILED·EXPIRED·잠금 대기·권한 회수를 확인했습니다. bootstrap에 2/4/8초 복구·수동 확인·재인증·만료 UI를 연결했습니다. 아래 항목의 후속 업무 endpoint/worker/UI 연결은 남아 있습니다.

- [ ] expected_version·Idempotency-Key·단일 DB 트랜잭션·감사 기록 기반 구현.
- [ ] 커밋 전 중단·커밋 후 응답 유실·고유키 경합·권한 재검사 구현.
- [ ] 결과 조회·UNRESOLVED·EXPIRED·410 응답과 최소 키 보존 구현.
- [ ] 운영 보관기간이 미정이어도 정책 주입 테스트로 만료 동작 검증. 자동 정리 실운영 활성화는 별도 확인.

검증 연결: E2E-38, E2E-39, E2E-40, E2E-44. worker 관련 검증은 P5/P7에서 함께 수행합니다.

## P4 셀러 신청과 파일

- [ ] 프로필·신청 초안·4단계 폼·필수 동의·제출·내 신청 화면 구현.
- [ ] 인증 이메일 snapshot과 명시 동기화, NEED_INFO·기한 연장 구현.
- [ ] private upload intent·순차 complete·첨부 해제·revision/소유권 검사 구현.
- [ ] 다른 탭 충돌·응답 유실·로그인 만료·순차 사진 처리 UI 연결.

검증 연결: E2E-02, E2E-03, E2E-04, E2E-13, E2E-15, E2E-26, E2E-27, E2E-32, E2E-41, E2E-42. 10장 업로드 시나리오는 테스트 정책이 허용하는 환경에서 수행하며 실제 운영 최대 개수로 단정하지 않습니다.
