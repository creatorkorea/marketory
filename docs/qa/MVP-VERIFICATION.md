# MVP 검증 결과와 운영 준비

기준일: 2026-10-23 (KST). 공개 웹은 https://marketory-silk.vercel.app, API는 https://marketory-api.onrender.com 이다. 이 문서는 2026-10-12–23의 실행 기록을 통합한 기준이며 실시간 서비스 상태판은 아니다.

**핵심 업무 흐름은 공개 환경의 합성 테스트 마켓으로 검증했다. 실제 행사 모집 개시는 아직 준비 단계다.** 실제 마켓 정보·운영 정책·담당자·백업 및 복구·안내 전달 체계가 남아 있다. 테스트 참가확정은 실제 계약·결제·개인정보 동의의 증거가 아니다.

## 검증 수준과 판정

| 구분 | 의미 |
|---|---|
| 공개 환경 확인 | 배포 웹과 API, 실제 인증 계정 및 저장소를 이용한 지정 테스트 흐름 |
| 로컬 확인 | 격리 PostgreSQL, 인증·메일·저장소 대역 또는 브라우저 fixture를 이용한 검사 |
| 사용자 확인 | 사용자가 수신함 등에서 확인했다고 보고한 결과 |
| 미검증 또는 보류 | 공개 조건 결정이나 추가 실행이 필요한 항목 |

아래 성공 결과는 표에 적힌 범위에 한정한다. AC 44개와 E2E 44개의 전체 통과율로 환산하지 않는다. 원본 CSV는 요구사항 기준이고, 개별 AC/E2E와 assertion의 대응을 확정한 실행 원장은 별도다. 과거 기록의 ‘미구현·미배포’는 해당 날짜의 상태이며 후속 결과는 이 문서를 우선 확인한다.

## 배포 기준과 증거 보관

마지막 확인한 공통 안내 배포는 웹 `944bf0a1bd287e1810e6fd0bf5ff097053f2dcb6`, API `9514edd4480e0840f67645635db62e1ccc75e276`, migration `20261022124634`다. Vercel Production Ready와 Render Live를 10-22 확인했고 10-23 공개 동선을 실행했다. 문서 통합 시 새 배포나 대시보드 재확인은 하지 않았다.

`output/` 증거는 Git 제외 로컬 파일이다. 이 문서는 결과 요약을 저장소에 보존하지만 증거 원본이 새 클론에 함께 제공되지는 않는다. 운영 인계 전에 토큰·서명 URL·개인정보 포함 여부를 점검하고 승인된 보관 위치와 보관기간을 정한다. CSV 원장에 과거 결과를 옮길 때는 정확한 case_id·revision·실행 시각·대역·기대 결과를 대조하고, 근거가 부족한 항목을 임의로 PASS 처리하지 않는다.

다음 순서는 실제 행사와 담당자 결정 → 운영 정책·백업 및 안내 방식 확정 → 실기기·실역할 리허설 → 필수 조건 검토 → 모집 개시 승인이다.
