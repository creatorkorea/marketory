## 2026-10-21 릴리스 전 재검증

사용자가 커밋·푸시·공개 배포를 요청했다. 기존 creatorkorea Vercel 프로젝트의 Production 브랜치는 `codex/communications`이며 이 브랜치의 푸시로 자동 배포된다.

- 단위 테스트 71개 통과.
- 서버 재시작 후 전체 브라우저 실행: 57개 통과, 마켓 생성 후 이동의 5초 대기 초과 1개. 최초 화면 컴파일이 함께 발생했다.
- 실패한 마켓 생성·편집·상태 변경·권한 배정 시나리오를 코드 변경 없이 2회 연속 재실행하여 모두 통과했다. 최초 실행의 시간 초과를 숨기거나 전체 단일 실행 성공으로 기록하지 않는다.
- 공개 배포 완료 여부와 커밋은 릴리스 결과에서 별도 확인한다. 실제 인증 계정 업무 E2E는 이번 재검증 범위가 아니다.
