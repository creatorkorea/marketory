# P0 Implementation Plan

> 실행: 현재 세션에서 직접 수행. 사용자 승인한 P0 범위에 맞춰 작성한다.

**Goal:** 웹·API·worker를 로컬 실행하고 재현 가능한 검사와 문서를 제공한다.

**Architecture:** npm workspace 웹과 uv Python 패키지. Postgres 트랜잭션과 OpenAPI로 경계를 고정한다.

**Spec:** [P0 설계](../specs/2026-10-08-p0-design.md)

## Global Constraints

Vercel 웹, Render API/worker, Supabase DB/Auth/Storage. Pretendard·기존 디자인 토큰 유지. 외부 배포·업무 기능은 이번 범위 밖.

## Review Focus

DB 미설정·장애를 성공으로 표시하지 않기; 비밀값 오류 노출 차단; worker 종료·재시도; 타입 드리프트; 작은 화면의 입력/초점.

## 작업

- [x] Python 기반: apps/api/pyproject.toml, src/marketory/{config,db,main,worker}.py, tests/. 먼저 health·설정·worker 실패 테스트를 작성하고 실패 확인 후 구현. uv run pytest 통과.
- [x] 웹 기반: package.json, apps/web/app/, components/ui/, scripts/sync-assets.mjs. 로컬 브랜드 에셋·토큰을 연결하고 UI 견본 제공. 타입검사·빌드·브라우저 확인.
- [x] 계약/실행: packages/types, scripts/export_openapi.py, Dockerfile, compose.yaml, .github/workflows/ci.yml. 타입 재생성 동일성, 실제 DB commit/rollback 확인. Docker 실행은 환경상 미검증.
- [x] 문서/검증: docs/LOCAL-DEVELOPMENT.md, docs/P0-VERIFICATION.md와 기존 시작 문서 업데이트. 전체 검사 후 차이 검토.

## 실행 기록

- 기존 앱/깃 저장소 없음. 현재 폴더에서 구축하며 기존 Word·디자인 원본을 보존한다.
- Docker 명령 없음. 컨테이너 실행은 검증되지 않은 것으로 남기고 로컬 Python/Node와 별도 개발용 PostgreSQL로 가능한 검증을 수행한다.
- 타입 생성 도구 호환성 때문에 TypeScript 5.9.3을 선택했다. Windows psycopg의 이벤트 루프 요구사항은 별도 runner로 해결했다.
- 최종 독립 검토의 설정 오류 비밀값 노출 1건을 실패 테스트로 재현하고 수정했다. 최종 DB 포함 테스트 8개 통과.
